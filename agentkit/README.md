# Agentkit: стартовый пакет для LLM-агента, работающего над Kaggriculture

Этот пакет — самодостаточный «запускник» для любого агента (Claude Code, Cursor,
Antigravity, Coding agent и т.п.). Агент может начать работу, имея только эту папку.

**Точка входа для агента:** `AGENTS.md` (миссия, ограничения, первые задачи).
Человеку достаточно сказать агенту: «Прочитай agentkit/AGENTS.md и начни с задачи T0».

## Содержимое
| Файл | Что это |
|---|---|
| `AGENTS.md` | Бриф агента: миссия, правила, DoD, первые задачи |
| `PLAN.md` | План на 5 фаз с чекбоксами и артефактами каждой фазы |
| `ARCHITECTURE.md` | Решение по базе знаний (гибрид ярусов, почему не граф, роль MCP) |
| `SOURCES.md` | Ссылки: соревнование, движок, датасет реплеев, MCP, статьи |

## Как это связано с репозиторием
Полный репозиторий содержит исполняемую часть (движок, eval-харнесс, агентов).
`agentkit/` — это **дистилляция решений и плана**, чтобы новый агент не повторял
исследование, а продолжал с того места, где остановился предыдущий.

Правило обновления: после каждой фазы обновляй чекбоксы в `PLAN.md` и
`ARCHITECTURE.md` — это и есть передача опыта между агентами.
