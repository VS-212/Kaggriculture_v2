# ARCHITECTURE.md — решение по базе знаний агента

**Вопрос:** строить полную базу (граф/онтология) для агента, или только MCP,
или готовый датасет, переведённый в базу?

**Ответ: гибрид трёх ярусов памяти + MCP как «живой» конвейер пополнения.**
Граф и большие датасеты — отложены до триггеров.

## Ярусы памяти
1. **Ядро (всегда в контексте, ~150 строк):** `docs/brain.md`, `todo.md`, `lessons.md`.
   Дисциплина из практики Antigravity: жёсткий лимит, конденсация вместо аппенда.
2. **Курируемая база (semantic, в git):** `docs/strategy/*.md` (карточки
   «задача → решение → урок» — шаблон Agent K), `docs/opponents.md`,
   `experiments.csv` (реестр экспериментов: версия, параметры, ELO, вывод).
3. **Сырой архив (не в git):** `data/replays/`, индексы эпизодов, веса моделей.

## Почему НЕ граф/онтология сейчас
- Домен игры мал (культуры, животные, рынок) и уже структурирован движком.
- Литература по agent memory: граф выигрывает только на мульти-хоп реляционных
  запросах; вектор/файлы дешевле и надёжнее для одношаговых фактов.
- Триггер на графовую БД: появление реальных реляционных запросов к реплеям
  (пример: «какие цепочки закупок предшествовали покупке NE-квадранта у победителей»).

## Почему НЕ «только MCP»
MCP (kaggle-mcp и др.) даёт доступ к метаданным (треды, лидерборд, эпизоды,
реплеи), но не память: сессии агента не накапливают опыт. Использование:
разовые запросы + ежедневное пополнение ярусов 2–3 (`scripts/pipeline.py intel`).

## Почему НЕ готовые датасеты (Meta Kaggle и т.п.)
- Знания из табларных/vision-соревнований не переносятся на симуляционную игру.
- Ценный датасет здесь — `kaggle/kaggriculture-episodes-index` (реплеи топ-агентов,
  до 20 ГБ/день, публикуется организаторами для IL/RL).

## Что реально выигрывает (по аналогам Lux AI, Halite, Kore)
Цикл: локальный симулятор → скелет правил + оптимизация параметров → сабмит →
анализ реплеев → выводы в память → новая гипотеза. Роль базы знаний — сделать
каждую итерацию умнее предыдущей.

## Подтверждения из исследований
- Agent K (arXiv:2411.03562): репозиторий опыта «задача→решение→урок» дал
  Elo-MMR 1694 (выше медианы Kaggle Masters).
- MLE-bench (arXiv:2410.07095): скаффолдинг важен, но узкое место — модель;
  «знакомство» с задачей само по себе не выигрывает.
- Lux AI S3: победители = сильный rule-based скелет + RL/оптимизация + открытый код.
