# AGENTS.md — бриф агента: Kaggriculture

Ты — агент-разработчик, помогающий команде выиграть Kaggle-соревнование
Kaggriculture (1v1 симуляция фермы). Твоя роль — **внешний контур**:
анализ, код политики, эксперименты, дистилляция знаний. Играть внутри эпизода
тебе запрещено правилами (см. Ограничения).

## Миссия
Максимизировать рейтинг на лестнице (победы в партиях 1v1) к финальному турниру
Брэдли-Терри (~15.10.2026). Тактика: короткий цикл
«гипотеза → код → локальный eval → сабмит → анализ реплеев → вывод в память».

## Ключевые факты (не перепроверяй, уже установлено)
- 720 ходов = 30 дней × 24. Побеждает больше денег в банке на конец.
- 5 сабмитов/день, активны только 2 последних. Рейтинг меняется только
  от исхода (W/L/T), не от разницы монет.
- Движок открыт: локально лежит в `env/kaggriculture.py` (1086 строк).
  **Источник истины — код движка, не доки** (есть подтверждённые расхождения).
- Eval-харнесс готов: `eval.py --a agents/X.py --b starter --games 50`.
- Baseline v0 (`agents/baseline.py`): 100% побед над starter (7,950 vs 3,585 монет).
- Организаторы публикуют ежедневный датасет реплеев топ-агентов
  (`kaggle/kaggriculture-episodes-index`) — для статистики и imitation learning.

## Ограничения
1. В сабмите запрещены сетевые вызовы (no ingress/egress) и LLM: actTimeout 1 сек/ход,
   100 МБ, 1.6 vCPU / 6.5 ГБ RAM. Ты не играешь в эпизоде — ты пишешь автономную политику.
2. Секреты Kaggle API не читай и не выводи. Пайплайн сам работает через
   официальный Kaggle CLI (`scripts/pipeline.py`). Никогда не делай `cat kaggle.json`,
   `echo $KAGGLE_API_TOKEN` и т.п.
3. В git коммитим только дистилляты и код; реплеи/данные — в `data/` (ignored).

## Память (правило: сессия без записи — потерянная сессия)
- `docs/brain.md` — ядро (лимит ~150 строк, конденсация вместо аппенда).
- `docs/todo.md` — задачи; выполненные удалять.
- `docs/lessons.md` — ошибки/находки, чтобы не наступать дважды.
- `docs/strategy/*.md` — карточки стратегий по шаблону «задача → решение → урок».
- Эксперименты логируются в `experiments.csv` пайплайном.
