# Brain — состояние проекта (core memory, лимит ~150 строк)

Обновлено: 2026-08-17 (фаза 0)

## Суть соревнования
Kaggriculture — 1v1 пошаговая ферма, 720 ходов (30 дней × 24). Побеждает максимум денег
в банке на конец. Рейтинг (Elo-подобный) + финал по Брэдли-Терри. 5 сабмитов/день,
активны 2 последних. Дедлайны: 23.09 вход, 30.09 последний сабмит, ~15.10 финал.

## Ключевые ограничения (проверены в правилах/движке)
- `actTimeout=1` сек/ход + общий overage-bank 60 сек; 100 MiB сабмит,
  1.6 vCPU / 6.5 GiB RAM / 8 GiB HDD.
- ПРАВИЛО 12: no ingress/egress → LLM не может играть в эпизоде. LLM = внешний контур.
- Приватный sharing competition code/data вне официальной команды запрещён;
  полный аудит: `docs/competition/rules-audit.md`.
- Движок открыт: env/kaggriculture.py (1086 строк) — источник истины, не доки.

## Текущее состояние (фаза 0 — фундамент)
- Инфраструктура: eval.py (матчи, агрегация, реплей), agents/baseline.py (v0).
- Пайплайн Kaggle (безопасный): scripts/pipeline.py (submit/monitor/intel/replays,
  dry-run) — секреты читает только официальный CLI из ~/.kaggle/ (см. docs/SECURITY.md).
  Git-guard: scripts/install-git-guard.sh + scan-secrets.sh (pre-commit блок).
- Стартовый пакет для другого агента: agentkit/ (AGENTS.md — точка входа).
- Baseline v0: жадный пшеничный фермер (полив > сбор > посадка > движение), продажа
  пшеницы каждый ход. Результат (50 партий, seeds 0..49):
  - vs starter: 100% побед, деньги 7,950 vs 3,585 (маржа +4,366)
  - vs random: 100%, 7,909 vs ~0
- Стартовая точка на лестнице: НЕ замерена (нужен API-ключ пользователя → первый сабмит).

## Открытые гипотезы (из фазы 0)
1. Цена пшеницы растёт к концу сезона (26 → 48 в реплее seed0: спрос города).
   Немедленная продажа субоптимальна → v1: придерживать часть урожая / спекуляция.
2. Животные (яйца: yield/tile/day 1.00 — лучший в таблице) против пшеницы (0.80).
3. Фермер-руки (fib-стоимость найма: 1,1,2,3,5...) окупаются при >=3-4 растениях.
4. Покупка квадрантов ($1k/$2k/$4k) — окупаемость против рынка.

## Решения (почему так)
- Память: markdown-ярусы (brain/todo/lessons/strategy) + эксперименты в SQLite. Граф/онтология
  отложены до появления реальных мульти-хоп запросов (триггер: реляционные вопросы к реплеям).
- MCP Kaggle: настроить как конвейер пополнения (эпизоды, реплеи, форум), не как память.
- Готовые датасеты: главный — ежедневный kaggle/kaggriculture-episodes-index (до 20 ГБ
  реплеев топ-агентов, для IL/RL). Meta Kaggle и сборники табларных решений — не приоритет.
